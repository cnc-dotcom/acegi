# RM CutPlan Studio — build a no-Python Windows installer

This repository is configured to build `RM_CutPlan_Studio_Setup.exe` on a Windows cloud runner. The target PC does **not** need Python installed; PyInstaller bundles the runtime into the application executable. Python is used only on the cloud build runner.

## Important truth about this package
This ZIP contains the source and automated Windows build workflow, **not a precompiled installer**. I cannot compile or test a Windows `.exe` from this Linux session. The installer must be generated by running the workflow on GitHub Actions.

## Create the installer without installing Python on your own PC
1. Sign in to GitHub and create a new **private** repository, e.g. `rm-cutplan-studio`.
2. Upload the contents of this folder to the repository, keeping `.github/workflows/build-windows-installer.yml` in that exact path. GitHub may hide `.github`; create the folders manually if needed.
3. Open the repository's **Actions** tab and enable Actions if prompted.
4. Select **Build Windows Installer** → **Run workflow** → **Run workflow**.
5. Wait for the green successful run, open it, then download the artifact named `RM-CutPlan-Studio-Windows-Installer`.
6. Extract the downloaded artifact ZIP and run `RM_CutPlan_Studio_Setup.exe` on Windows. Follow the setup wizard and select the desktop shortcut option if desired.

## What's included
- Plate nesting and schematic layout preview
- Structural stock-length optimization
- Manual, Excel and limited DXF input
- PDF and Excel report export
- Report number and logo selection

## Current limitations
- Plate nesting is rectangular shelf-style placement, not true-shape nesting.
- DXF closed polylines/circles are converted to bounding rectangles; units are assumed mm.
- Length cutting uses a heuristic; validate kerf and end trim.
- No machine-ready G-code/NC output.
- Four existing algorithm unit tests are run during the build. This does not constitute full production validation or a test on every Windows PC.

For a commercial/production rollout, more validation, error handling, and actual machine-specific trials are required.
